# 학습일지 - 2026-07-31 (Week 2, GO2교육 4일차)

## 오늘 배운 것  
### 새롭게 알게 된 점 3줄 요약

- Gazebo 시뮬레이터에서 Go2가 통과할 수 있는 터널 구조물을 직접 생성하고 배치해보았다.
- ROS 2 bag으로 LiDAR, odom, TF 등의 토픽을 녹화한 뒤 RViz2에서 다시 재생하고 시각화하는 방법을 배웠다.
- RViz2의 Fixed Frame을 `odom`, `base_link`, `velodyne`으로 변경하면 같은 센서 데이터도 서로 다른 기준 좌표계에서 다르게 보인다는 것을 확인하였다.

## 직접 해본 것 / 성공한 것

- SDF 형식으로 벽 2개와 천장 1개로 구성된 터널 모델을 생성하였다.
- `spawn_entity.py`를 이용해 Gazebo 월드에 터널을 추가하였다.
- Go2가 터널을 통과하는 동안 전체 ROS 2 토픽을 rosbag으로 녹화하였다.
- 녹화한 `/velodyne_points`를 RViz2에서 `PointCloud2` 형태로 재생하였다.
- Fixed Frame을 `odom`, `base_link`, `velodyne`으로 각각 변경해 영상을 촬영하고 차이를 비교하였다.
- `/velodyne_points`의 `frame_id`가 `velodyne`이라는 것을 직접 확인하였다.
- Python으로 `/cmd_vel`에 `Twist` 명령을 주기적으로 발행하는 사각형 주행 스크립트를 작성하였다.
- 전진 속도와 회전 각속도를 이용해 한 변 1 m의 정사각형 주행 시간을 계산하였다.

## 막힌 것 / 이해가 안 되는 것  
### 다음 Q&A 때 질문할 목록

- rosbag을 RViz2에서 재생할 때 `/clock`, `use_sim_time`, Fixed Frame 설정이 서로 어떤 관계를 가지는지 더 정확히 이해하고 싶다.
- `RobotModel`을 rosbag 재생 환경에서 표시하기 위해 `/robot_description`, `/joint_states`, `/tf`, `/tf_static`이 각각 어떤 역할을 하는지 궁금하다.
- `/cmd_vel` 토픽에 값이 정상적으로 발행되는데도 Go2가 움직이지 않는 경우, 어떤 제어 노드와 컨트롤러 상태를 우선 확인해야 하는지 궁금하다.
- Fast DDS의 `RTPS_TRANSPORT_SHM Error`가 발생하는 정확한 원인과 `/dev/shm` 공유 메모리 파일의 역할을 더 알고 싶다.
- 시간 기반 개루프 제어로 사각형을 주행할 때 발생하는 오차를 줄이기 위해 odom 피드백을 사용하는 방법이 궁금하다.
